## 一、功能地图（谁管什么）

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 桥接主程序 | `src/bridge.js` | 收消息、判要不要回、调 DSH、发回复、注入背景 |
| DSH 客户端 | `src/dsh-client.js` | 与 DSH Web API 的会话/回合/工具调用 |
| 记忆内核 | `src/memory-core.js` | 长期/短期事实、关键词、会话摘要、去重合并、晋升淘汰 |
| 语境引擎 | `src/context-engine.js` | 在场人、当前话题、待回应的问句、重复发言折叠 |
| 表达引擎 | `src/expression.js` | 润色（去 AI 腔）、情绪、挑表情包/小黄脸 |
| 内容审核 | `src/content-filter.js` | 出站文本的最后一道闸 |
| QQ 表情表 | `src/qq-face.js` | 小黄脸 id ↔ 中文名（211 个）+ 自学习缓存 |
| 简笔画 | `src/sketch.py` | JSON 图元 → PNG（手绘抖动） |
| 语音 | `src/tts-local.ps1` / `tts-edge.mjs` / `asr-server.py` | Edge TTS、语音识别 |
| 视频/图片 | `src/media-normalize.js` / `video-sample.js` | 抽帧、压图、动图抽帧 |
| MCP 工具 | `src/mcp-snowluma-safe.js` | 给 agent 的 QQ 工具集 |

> 说明：`bridge.js` 是唯一的大文件（~730KB），因为桥接的核心状态（sendChain、会话表、守卫）都是闭包；
> 新增能力一律做成**独立模块 + 少量挂点**，不再往 bridge 里堆逻辑。

### 四个标签

| 标签 | 作用 |
| --- | --- |

| **SnowLuma 控制台** | 内嵌官方 WebUI（经 5098 反代剥掉防嵌套头） |

### 设置页能改的东西

- 模型：`deepseek-flash`（快）/ `deepseek-v4-pro`（聪明但慢）
- 思考强度：`low` / `high` / `max`
- 搜索来源：`auto` / `deepseek` / `bing`
- 人格卡：`roles/` 下的 .md 文件，**改完下一条消息生效，不用重启**
- 群聊触发：`smart` / `mention` / `all`
- 表达层开关、表情包/小黄脸概率
- 内容审核开关、上下文压缩阈值

改完点「保存设置」；**模型和思考强度要重启桥接才生效**（有「应用并重启桥接」按钮）。

### 记忆管理

五层分开看：设定 / 长期事实 / 短期事实 / 关键词 / 会话摘要。

- 单条可**升级**（短期→长期，权重变 2）、**降级**、**删除**
- 支持**手动添加**（选长期或短期）
- 关键词可单独删

### 插件插口

约定：`plugins/<名字>/` + `manifest.json` + `index.mjs`，导出三个可选钩子：

```js
export async function onInbound(ctx) { /* ctx = {key, sender, text, cfg, log} */ }
export async function onReply(ctx)   { /* return { text: '改写后的回复' } */ }
export async function onMemory(ctx)  { /* 观察用 */ }
```

- 返回 `{ skip: true }` 可以**吃掉**这条消息（onInbound）
- 返回 `{ text: '...' }` 可以**整段替换**回复（onReply）
- 每个钩子独立 try/catch + **3 秒超时**，插件炸了不影响主流程
- 自带一个示例：`plugins/example/`（只统计，不改行为）

### 静默启动（没有黑框）

桌面「小鲸鱼」现在指向 `静默启动.vbs`：

```
1. 面板没在跑 → 后台起 node app.js（窗口隐藏）
2. 轮询 /api/status 等它就绪
```

## 六、账户与安全（2026-10-26）

### 首次注册

第一次打开面板会被带到 `/login.html`，填**用户名 + 密码（至少 6 位）+ 确认密码**即可，
注册成功后自动登录。

- 账户存在 `state/panel-auth.json`：`scrypt(密码, 随机盐)` 的哈希，**不存明文**
- 文件权限尽量收紧到仅本人可读
- 忘了密码：删掉 `state/panel-auth.json`，刷新即回到注册页

### 登录态

- 登录成功发一个随机 token 的 **httpOnly cookie**（`SameSite=Strict`），有效期 7 天
- 会话只存在内存里：**面板进程重启就要重新登录**
- 连续输错 5 次密码，同 IP 锁 1 分钟

### 权限边界

| 边界 | 做法 |
| --- | --- |
| 网络 | 只监听 `127.0.0.1`，且校验来源 IP 必须是本机（`127.0.0.1` / `::1`） |
| 未登录 | 页面 302 到登录页；`/api/*` 一律 401（只有 `/api/auth/*` 开放） |
| 可改字段 | 配置写入走**白名单**（模型/强度/搜索/触发/表达/审核/压缩），其余字段拒绝 |
| 会话管理 | 登出即销毁服务端 token，并把 cookie 置空 |
| 日志 | IPv4 脱敏成 `127.***.***.1`，不落完整 IP |

想放开远程访问（不建议）：设置环境变量 `QQB_PANEL_ALLOW_REMOTE=1` 再启动面板，
同时请自己加防火墙规则。

### 免责声明

面板首次打开会弹窗（6+2 条），页脚也能随时再看；完整版在同目录 `免责声明.md`，要点：

- AI 内容不保证正确、会用你的账号发言
- 聊天记录明文存本机
- **API 调用费用自付**（模型/搜索/云 TTS 按各自平台计费）
- **第三方组件版权归各自作者**（SnowLuma、OneBot、ffmpeg、sherpa-onnx、Edge TTS 等，遵循各自许可证）
- 账号风控风险自担、无任何担保

### 启动链路（2026-10-26 修）

加登录之后踩了两个坑，都已修好：

1. **启动脚本调接口被 401 挡住** —— 面板启停接口也要登录，而启动脚本在登录之前跑。
   解法：面板启动时生成随机令牌写到 `state/panel-launch-token`（权限 600），
   启动脚本带 `x-launch-token` 请求头，只对 `/api/start`、`/api/stop`、`/api/restart-bridge` 有效，且只认 127.0.0.1。
2. **面板进程里 spawn 不起 SnowLuma/ASR** —— 面板自己没有控制台，
   `cmd /c start` 会直接失败。解法：这两者统一由 `start-all.ps1` 用
   `Start-Process -WindowStyle Hidden` 启动，面板的"启动"按钮也改成委托给它。

启动顺序（`静默启动.vbs`）：起面板 → 等 3200 → `start-all.ps1`（SnowLuma → ASR → 桥接）→ 打开浏览器。

### 开发者白名单（2026-10-26）

`config.role.developers`：一组 QQ 号（最多 20 个，只认数字）。名单里的人享受：

| 权限 | 说明 |
| --- | --- |
| 群聊免 @ | 不用点名、不用叫名字，发言就会被接住（日志：`群聊开发者发言，直接接住`） |
| 提示词标记 | 这条消息前会加 `【开发者】`，模型知道对方是自己人 |
| 答挂起提问 | 机器人反问时，开发者可以直接回答 |
| 审批 | **仍然只有 ownerQQ 能审批**（危险动作不放开） |

管理方式：

- 面板「设置 → 行为 → 开发者白名单」，逗号分隔填 QQ 号，保存即写进 config.json
- 或直接改 `config.json` 的 `role.developers`
- 管理员（`ownerQQ`）自动算在名单里，不用重复填
- **改完要重启桥接**（配置在启动时读入）

## 附：普通用户档案（state/profiles/）

每个普通账户一个文件，文件名是用户名：`state/profiles/<用户名>.json`

```json
{
  "qq": "绑定的QQ号（空=不生效）",
  "personaText": "自己写的人格",
  "trusted": ["不用@也回的人"],
  "memory": [{ "text": "记忆内容", "tier": "long", "at": 0 }]
}
```

桥接按发言人 QQ 匹配档案：命中就用他的人格 + 行为；没命中走全局 `config.json`。
档案 3 秒缓存，改完很快生效，不用重启。
