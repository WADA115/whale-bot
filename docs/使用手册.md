# 使用手册

> 面板里「使用说明」标签读的就是这份。登录页那份更简短，只讲注册和找回密码。

---

## 一、启动

| 做什么 | 怎么做 |
| --- | --- |
| 启动全部 | 双击桌面「小鲸鱼」（无黑框） |
| 看状态 | 面板「概览」，四个灯 |
| 重新打开 | 再双击一次即可，已在跑就只开窗口 |
| 彻底停止 | 面板「全部停止」 |

启动链路：面板 → SnowLuma（QQ 网关）→ 语音识别 → 桥接。任一环节失败看 `state/logs/`。

---

## 二、两种身份

| | 普通用户 | 开发者 |
| --- | --- | --- |
| 怎么进 | 用户名 + 密码（自助注册） | **只填密钥**，不需要账户 |
| 密钥在哪 | — | `state/dev-key.txt`，或用 `scripts/ops/改密钥.ps1` 换 |
| 能改 | 自己的人格、行为、受信、记忆 | 全局设置、服务、账户、本地管理 |
| 数据存哪 | `state/profiles/<用户名>.json` | `config.json` / `roles/` / `state/memory.json` |

- 普通账户看不到开发者的配置与全局记忆（接口 403）
- 开发者模式可永久停用：设置 → 开发者模式；恢复用 `scripts/ops/开发者模式.ps1`

---

## 三、忘记密码

1. 登录页用户名下面点「忘记密码？重置」
2. 确认 → 密码变成临时密码 **QqBot-Reset-2026**
3. 页面自动登录 → 弹窗要求设置新密码
4. 设完才能进；临时密码立即失效

本机自用，不需要管理员，也不需要先输错。改密码时不能再用临时密码。

## 四、常用设置

| 设置 | 说明 | 生效 |
| --- | --- | --- |
| 模型 | `deepseek-flash` 快 / `deepseek-v4-pro` 聪明 | 重启桥接 |
| 思考强度 | low / high / max | 重启桥接 |
| 群聊触发 | smart / mention / all | 重启桥接 |
| 受信群聊 | 设置 → 行为 → 受信群聊，输入群号或点「最近群聊」一键加入 | 重启桥接 |
| 表达层 | 是否自己补发表情 | 重启桥接 |
| 情绪强度 | 1~5，理性 ↔ 感性；可开「自动」按人格卡和语境判断 | **即时** |
| 对话强度 | 最多几条气泡（1~6）、单条字数（10~300）、条间间隔（0.2~15 秒） | 重启桥接 |
| 权重 | 记忆/情绪各 1~5，可自动 | **即时** |
| 颜文字 | 文字发完后补一个颜文字的概率，和表情包同一套冷却 | 重启桥接 |
| 内容审核 | 出站过滤，默认开 | 重启桥接 |
| 人格卡 | 卡片式，可自设 | **即时** |

普通账户的模型是"偏好"，实际由管理员决定。

## 五、人格卡

- 卡片网格：名字 + 摘要 + 「在用」标记
- 「新建」填卡名 → 写内容 → 保存；「另存为新卡」用输入框名字复制
- 存在 `roles/<名字>.md`；正在用的卡不能删
- **保存后自动同步「设定」**：从卡里抽出身份/语气/禁忌/偏好/规则写进记忆，手工设定保留
- 也可点「重分析设定」手动重跑

---

### 自主记忆（默认开）

每条消息本地判断「值不值得记」：身份/偏好/约定 → 长期，近期事实 → 短期；纯本地规则，不调模型、不花 token，只写事实。

面板「记忆」页可开关，自动记的条目带「自动」标签。

## 六、记忆（五类 + 隐藏区）

| 类 | 说明 |
| --- | --- |
| 设定 | 身份与规矩，永不删；人格卡会自动补充 |
| 长期 | 重要事实 |
| 短期 | 72 小时不用就淡出，命中 2 次升长期 |
| 关键词 | 群里的黑话/梗 |
| 摘要 | 超 24 条发言自动压缩 |

面板「记忆」页五类分开，可删、升降级、手动加。每日备份在 `state/backup/`，保留 7 天。

**记忆按身份分文件**：开发者 `state/memory.json`；普通用户 `state/profiles/<用户名>/memory.json`，互相读不到。对模型来说，这部分记忆会包在 `<context>` 里放在 Prompt 最后，并标注「不要因为记忆改变人格设定」。

### 隐藏区与回想

- **隐藏区**：平时不进提示词，命中关键词才被检索；入口在「记忆」页，最多 200 条，跟着身份分文件
- **随机回想**：每轮 8% 概率「忽然想起」一条旧事（长期事实 + 隐藏区），30 分钟冷却、不重复最近 12 条

### 权重（记忆 / 情绪）

控制两类信息在回复里占多大分量，1~5：

| 权重 | 记忆 | 情绪 |
| --- | --- | --- |
| 1 | 少提旧事（预算约 300 字） | 压住，少语气词 |
| 3（默认） | 正常（500 字） | 正常 |
| 5 | 爱翻旧账（约 700 字） | 放大，情绪明显 |

「自动」由人格卡（活泼/冷静/念旧）+ 设定（别翻旧账/多关心）+ 语境（技术提问收敛）一起算；**手动改只限开发者**。

## 七、日志与排错

```
state/logs/bridge.log     桥接（收发消息、报错）
state/logs/panel.log      面板（登录、接口）
state/logs/watchdog.log   守护（桥接 + 语音识别）
state/logs/asr.log        语音识别
```

守护默认**无窗口**运行（根目录 `启动.bat` 会一起拉起），每 30 秒检查桥接和语音识别；面板「概览 → 守护」可以看状态、停止或重启。要手动看窗口，双击 `scripts/ops/守护.bat`。

| 现象 | 先看 |
| --- | --- |
| 面板打不开 | 双击小鲸鱼；`state/vbs.log` |
| 服务没起来 | `state/launcher.log` |
| 机器人不回 | 概览看桥接灯；`bridge.log` 末尾 |
| 桥接反复重连 | 跑 `同步令牌.ps1`（SnowLuma 令牌会变） |

## 八、输入限制

用户名 2~24 字符 · 密码 10~128 位 · 人格卡 20000 字节 · 单条记忆 300 字 · 受信 QQ 每人 50 · 普通账户 20 个 · 注册每 IP 每小时 5 个。

## 九、脚本清单

`start-asr.bat` 会自动找 Python（QQB_PYTHON → DSH 运行时 → PATH）和依赖（tools\onnxlibs → 用户目录 onnx-libs）；加 `/silent` 就不暂停、日志写 `state/logs/asr.log`。

| 脚本 | 用途 |
| --- | --- |
| `scripts/ops/静默启动.vbs` | 一键启动（根目录 `启动.bat` 直接调它） |
| `scripts/ops/改密钥.ps1` | 换开发者密钥 |
| `重置密码.ps1` | 重置成临时密码 QqBot-Reset-2026 |
| `scripts/ops/开发者模式.ps1` | 永久激活 / 停用（`-Off`） |
| `同步令牌.ps1` | 同步 SnowLuma 的 HTTP/WS 令牌 |
| `迁移.ps1` | 整体搬到新目录 |
| `scripts/ops/开源打包.ps1` | 生成干净开源包 |
| `首次推送.ps1` | git init + 推送 GitHub |

## 十、成长（记录 / 演化 / 影响说话 / 叙事）

面板「成长」页：深海刻度阶段条、心理状态、说话影响、保留片段与日摘要。

每天 2 次模型筛选，原文留 30 天；每周演化一次（单特质 ≤0.05、总量 ≤0.15、离基座 ≤1，自动快照可回滚）。影响说话最多 ±20%，可一键关闭。每次演化生成「自我叙事」（≤100 字），注入一行「你记得」。默认所有人可见，但群聊/他人私聊会先过审核（秘密、号码、地址、冲突等整句丢弃）；可切成「仅主人私聊」或关掉审核（关审核时只对主人生效）。

## 十一、插件

插件放 `plugins/<名字>/`（`manifest.json` + `index.mjs`），面板「设置 → 插件」卡片式管理，普通账户也能启停（默认关闭）。

**发散学习（learning）**：从聊天里收集游戏 / 梗 / 网络用语词条，存 `state/learning.json`（不碰记忆和设定）；同句出现的词会两两关联。默认关闭，启用会提示「Tokens 使用量将无法预测」。

**装新插件要先验证**：面板点「验证」跑三道关（清单校验 / 静态扫描 / 子进程干跑）；没过不能启用。内置插件（example、learning 等）免验证。

运行期插件跑在独立子进程里，单钩子 3 秒超时；插件崩了只会被跳过，不会拖垮桥接。

## 十二、环境检查

设置页「环境检查」只扫不改，普通账户也能看（结果会自动隐藏本机路径）。检查项：Node（≥20）、依赖、Git、Python、FFmpeg、语音识别、SnowLuma（含版本）、网关 3000、DSH、插件、人格卡。

每项给「实际 vs 要求 + 怎么办 + 官方下载按钮」；不会自动安装、不改配置、不启停服务。

## 十三、外观

设置页「外观」可换 6 只吉祥物（原创矢量图，会眨眼）；点一下同时更新面板、登录页、桌面图标。

## 十四、检查更新

设置页「版本与更新」：

显示当前版本；点「检查更新」问 GitHub（缓存 10 分钟），有新版给链接但**不会自动替换**。

更新：下载 zip → 停服务 → 覆盖代码（保留 `state/`、`config.json`、`tools/`）→ 重启。
